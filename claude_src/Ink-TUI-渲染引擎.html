Ink 是什么

原文“Ink 是什么”

原文说，Ink 是 Vercel 开发的开源框架，让开发者用 React 组件描述终端界面。

核心原理

Ink 的核心是一个自定义的 React reconciler，基于 react-reconciler 库实现。reconciler 是 React 里负责把组件树变成实际输出的那一层。

基本元素

原文把 Ink 的基本元素和 HTML 做了对照：

Ink 组件 作用 类似 HTML
<Box> 布局容器（flexbox） <div>
<Text> 文本，支持颜色和样式 <span>
<Newline> 换行 <br>
<Spacer> 弹性空白 flex: 1
<Transform> 文本变换 CSS text-transform
<Static> 静态子节点 ReactDOM.hydrate

和 Web 上的 React 有什么不同

维度 标准 React（Web） Ink（终端）
渲染目标 DOM（浏览器） 终端字符矩阵
布局 CSS（像素级） flexbox（字符级）
颜色 CSS 颜色 ANSI 转义码
交互 鼠标、触摸 键盘输入
滚动 CSS overflow 终端原生滚动
动画 CSS transitions 帧刷新（setTimeout）
组件库 极其丰富 有限的自定义组件

Ink 渲染的性能特性

原文“Ink 渲染的性能特性”

终端是字符矩阵，不是像素平面。原文列了 Ink 渲染的四个特性：

特性 做什么
完整帧重绘 每次状态变化，都算出新的虚拟终端状态，再用 ANSI 码增量更新
批处理 靠 React 的批处理，短时间内连着几个 setState 只写一次终端
阈值控制 有最小更新间隔，默认 16ms（约 60fps），避免重绘太频繁
增量输出 只把变化的部分用 ANSI 码写进终端，不是全部重绘

第一条叫“完整帧重绘”，第四条说“不是全部重绘”。按第一条自己的说明，两条讲的是同一件事：每次都算出完整一帧，但只把变化部分写进终端。
